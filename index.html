What is the point of language in lang="en" in html tag

The primary point of <html lang="en"> is to declare the default language of a web page's content

  1. Assistive technologies, especially screen readers used by visually impaired individuals, rely on this attribute to know how to pronounce words.
  2. Web browsers use this tag to understand if a page needs to be translated for the user. It also tells the browser which dictionary to use for spell-checking in editable text areas
  3. Search engines like Google and Bing use the language tag to better index your site. It helps ensure that your English website is accurately served to users who are searching for answers in English

If you write a page in English but leave out the lang attribute, a user's screen reader might default to a Spanish or French accent profile.It will try to read English words using foreign phonetic rules, resulting in an unintelligible mess.

When you place lang="en" inside the root <html> tag, all other elements on the page inherit English as their default language. However, if you have a specific section or paragraph on your page written in a different language, you can override the default locally

Can <p> contain <li> inside it?

Putting a <ul>, <ol>, or <menu> inside a <p> tag is invalid HTML and will break your page layout.While an <li> can hold block-level elements, a <p> tag is strictly forbidden from containing block-level elements—including lists. However browsers are forgiving and they usually close the p tag before list starts and render the paragraph and list
